# 1.x to 2.x

- `EnrichModel` and `EnrichModelList` do not receive the `serverRequest` within the parameter `context` anymore. If you still need such a functionality you have to create a custom handlers.
- `createUpdateHandler` does not have a logic anymore to cleanup `id`, `createdAt`, `updatedAt`, `_embedded`, `_links` within the request body anymore. If you still need such a functionality you have to create a custom `createUpdateHandler`
- `createTypedHandler` does not support undefined for schema anymore. drop those properties to get the same behavior.
